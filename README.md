# Визитница (BizCards)

Приложение-визитница для Android на Kotlin.

## Возможности
- Список визиток (имя, компания, телефон, email, заметка)
- Поиск по всем полям
- Добавление / редактирование / удаление
- Долгое нажатие на карточку: позвонить или удалить
- Данные хранятся локально в Room (SQLite)

## Как собрать
1. Откройте папку проекта в Android Studio (Hedgehog или новее).
2. Дождитесь синхронизации Gradle.
3. Запустите на эмуляторе или устройстве (minSdk 24, targetSdk 34).

## Структура
- `Card.kt` — сущность Room, DAO, база данных
- `MainActivity.kt` — список, поиск, звонок
- `EditCardActivity.kt` — форма добавления/редактирования
- `CardAdapter.kt` — RecyclerView-адаптер

## Сборка APK через GitHub (без компьютера)
1. Зарегистрируйтесь на https://github.com и создайте репозиторий (например, `BizCards`).
2. Загрузите в него все файлы проекта (через сайт github.com: Add file → Upload files, с телефона тоже работает).
3. Перейдите во вкладку **Actions** — сборка запустится автоматически (зелёная галочка = успех, ~5–10 минут).
4. Откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `BizCards-apk` — там файл `app-debug.apk`.
5. Установите APK на телефон (разрешите установку из неизвестных источников).
